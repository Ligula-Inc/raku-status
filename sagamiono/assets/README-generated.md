# 生成した絵（写真ではありません）

ここにある `tx-*.jpg` は、**生成 AI で作った素材**です。原本は `work/`（公開されない）にあります。

| ファイル | 中身 | 使っている場所 |
| --- | --- | --- |
| `tx-rock.jpg` | 濡れた石肌 | 湘南台「日帰りで入る」の頭 |
| `tx-steam.jpg` | 黒地に立つ蒸気 | 湘南台「サウナ」の頭 |
| `tx-yumen.jpg` | 湯の面の波紋 | 湘南台「館内」の頭 |
| `tx-yuge.webp` | 湯気 | 帯の背景 |

## 決めごと

- **実在する施設（湘南台）の写真の代わりには使わない。** 大浴場・露天・サウナ・外観そのものを
  生成した絵で見せると、行ったときに違う。だから素材（石肌、蒸気、湯の面）だけにして、
  キャプションは必ず「イラスト：」で始める。
- **相模大野（未開業）**は完成予想図を `cg-*.webp` として使い、キャプションは「イメージ写真／
  実際のものとは異なります」。こちらはページの仕組みが自動で付ける。
- 施設そのものの写真が要る場所は、先方に原本をもらう。
  一覧は maimai_os の `ligula/projects/raku/shonandai-photo-request.md`。
