# assets — サイトに出る画像だけ

**ここに置いたものは公開されます。** 検討用・ボツ・原本は `work/`(git に入らない)へ。

## 名前のつけ方

| 先頭 | 何に使うか | 例 |
| --- | --- | --- |
| `ph-` | 写真(実写) | `ph-yugawara-town.jpg` |
| `tx-` | 地と質感(和紙、墨、水紋、湯気、石) | `tx-washi.webp` |
| `fig-` | 図版(地図、ピクトグラム、手順の図、断面図) | `fig-michi-map.png` |
| `vid-` | 動画 | `vid-yu-loop.mp4` |

いま入っている実写は、取り込んだときのファイル名のままです(出典を追いやすいため)。

## 置いたら、やること

1. **拡大して、画像の中に文字が混ざっていないか見る**(ChatGPT は日本語の文字を崩します)
2. **Web 用に変換する。**1枚 150KB 以下が目安

   ```bash
   magick in.png -resize 2000x -strip out.jpg
   cwebp -q 82 out.jpg -o out.webp
   ```

3. **`credits.json` に1行足す。**AI で作ったものは、そう書く

   ```json
   { "file": "tx-washi.webp", "source": "AI生成 (ChatGPT / GPT Image)",
     "prompt": "和紙の表面を真上から…", "use": "湯の道 章の地", "date": "2026-11-12" }
   ```

## 守ること

- **館内・浴室・サウナ・料理の写真は、撮るまで置かない**
- **AI で作った画像を、実在の場所の写真として使わない。**地と質感、図版、それだけ
- CC BY-SA の写真は、加工して配ると同じライセンスが要る。切り抜きと縮小に留める
