# らくすけ（キャラクター）の置き場所

ここに次の名前で置くと、サイトに自動で出ます。置かなければ何も出ません。

| ファイル名 | 使われる場所 | 形 |
| --- | --- | --- |
| `rakusuke.png` | 下の帯（全ページ） | 全身。背景は透過 |
| `rakusuke-face.png` | もう一軒のお店のバナー | 顔だけ。背景は透過 |

- **透過 PNG** でお願いします（背景が白いと四角く出ます）。
- 大きさは長辺 600〜1200px あれば十分です。
- ここ（`shared/assets/`）に置くと、相模大野・湘南台の両方に配られます。
  片方だけに出したいときは `sites/<店>/assets/` に置いてください。
- 管理画面の「写真」からも入れられます（同じ名前にすること）。
